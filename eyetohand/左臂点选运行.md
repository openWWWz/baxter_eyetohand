# Baxter 左臂点选控制

独立程序 `test_grasp_baxter_left.py`，原右臂程序及其启动脚本保持不变。
默认读取 `8/hand_eye_result.json`；该文件是固定相机到 Baxter 基座的变换，采集时使用右臂不影响它供左臂使用。相机与机器人基座须保持标定时的位置；左臂使用自身当前姿态、关节、IK 及夹爪，不做坐标镜像。

## 左臂点选

在本机图形桌面的另一个终端执行：

```bash
cd /home/robot24/wzy_ws/baxter_worksapce/eyetohand
python test_grasp_baxter_left.py \
  --calibration 8/hand_eye_result.json \
  --execute --speed 0.1 --stop-above-mm 7
```

默认目标沿基座 Z 轴抬高 7 mm，直接到表面选点可改为 `--stop-above-mm 0`。
移除夹爪上的标定板，先手动调整左臂朝向，并确保运动范围内没有障碍。

| 操作 | 功能 |
| --- | --- |
| 左侧彩色图上左键单击 | 只选择目标并显示坐标 |
| p | 取按键时左臂当前朝向，预检 IK 后移动到目标 |
| o | 张开左侧电动夹爪 |
| c | 到达目标后闭合左侧电动夹爪 |
| r | 沿到点方向退回约 8 cm |
| x | 取消后续动作并请求保持当前位置 |
| q / Esc | 退出窗口 |

程序不自动使能或标定夹爪；开合操作需左侧电动夹爪已准备好。若只需要到点，可以直接选点、按 p，无需先操作夹爪。
省略 `--execute` 时只预览，不发送运动或夹爪命令。
额外 TCP 偏移默认 `0 0 0`，左夹爪若有额外改装需单独确定 `--tcp-offset-mm`，不要沿用右臂板安装变换或其他机器人的夹爪补偿。

只读检查左臂状态、图像、内参及当前姿态 IK：

```bash
python test_grasp_baxter_left.py --calibration 8/hand_eye_result.json --headless-check
```

## 接口与日志

- 左臂末端：`/robot/limb/left/endpoint_state`。
- 左臂 IK：`/ExternalTools/left/PositionKinematicsNode/IKService`，请求坐标系为 `base`。
- 运动使用 `baxter_interface.Limb('left')`，IK 返回值只接受七个左臂关节。
- 夹爪使用 `/robot/end_effector/left_gripper/` 下的状态、属性、命令接口。
- 窗口标题包含 `Baxter Left Grasp`，界面标有 `LEFT`。
- ROS 节点使用独立前缀 `baxter_click_grasp_left`；运行日志保存到 `grasp_baxter_left_时间戳/`，不会与右臂日志混用。

路径沿用原程序的小段 IK 与关节位置控制；没有环境碰撞规划，不能保证严格直线或每时刻完全恒定朝向。软件停止依赖 ROS 通信，紧急情况使用机器人急停。
